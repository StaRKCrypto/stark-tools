How keys work

  • Stored only in localStorage key stark.live.vault.v1 on your device.
  • Never written into this GitHub Pages repo as server state we control.
  • DRY_RUN defaults ON. Live orders need: turn DRY_RUN off + explicit Arm confirm.
  • Arm flag is sessionStorage — refresh disarms.
  • Burner wallets only. NFA. We cannot recover keys.
