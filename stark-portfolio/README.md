## What this sample is

A **fake portfolio UI stub** with hardcoded demo stats. Paste nothing, connect nothing —
open the HTML stub and see how a Stark Portfolio glance might look.

## Run the stub

```bash
# open in any browser
open demo/index.html   # or: xdg-open / python -m http.server
```

Or:

```bash
cd demo && python3 -m http.server 8765
# then visit http://127.0.0.1:8765
```
